# Supplied source attribution

The user supplied `maritime-dither(1).zip`, containing the Maritime dither kit.
Its README states: "Three ways we dither on maritime.sh. All MIT-style, use freely."
The source files and that README are retained under `vendor/maritime-dither/`.

The kit's DitherCanvas identifies its wave-and-dither implementation as adapted
from `reactbits.dev/backgrounds/dither`. That attribution is retained in the
original file and noted in the standalone port.

This game adapts the supplied wave shader, Bayer dither method, and ShipCrossing
hull. No third-party fonts, music, game art downloads, or external runtime packages
are included. The visible boat, rocks, water, and preview are rendered from code.
