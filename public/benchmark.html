What the numbers mean

Render JS time measures only the synchronous production renderer.draw call. Observed frame intervals and FPS use real requestAnimationFrame timestamps, including rendering, browser scheduling, and other work between callbacks. This is browser callback cadence, not a guarantee that every frame reached the display. Canvas raster/compositor work may occur asynchronously and is not all captured by render JS time. No getImageData flush, mocked Canvas, synthetic frame times, or headless arithmetic FPS is used. Module import, asset load, and initialization are excluded. The logical scene is always 1180 × 757 CSS pixels, even if the browser window is smaller. Each renderer chooses its own production backing resolution; results report it explicitly, so these runs compare production configurations rather than equal pixel workloads. Loading both variants shares the same asset URLs and Three.js module. Hidden tabs abort rather than yield misleading completed scores.
